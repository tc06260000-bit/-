# 测试与限制

日期：2026-10-17。

## 已完成

Python 3.12.14 环境中运行：

```text
python3 -m unittest discover -s scripts -p '*_test.py' -q
```

**69 项测试通过**。运行时只使用 Python 标准库，代码以 Python 3.10+ 为目标；本次没有在其他 Python 版本逐个运行。

覆盖内容包括：

- React Router flat-array 引用、跨脚本分片和旧版 `__NEXT_DATA__`。
- 按当前分支父节点取顺序，排除旧分支和隐藏/工具信息。
- 3000 条消息的长链，链断裂、循环、空白、重复字段、深度和大小限制。
- 未完成的可见消息、未知内容、附件、图片和音视频明确失败。
- 严格 URL、单次抓取、重定向、响应类型、大小、截断和超时。
- 新建独立输出目录、失败清理，不能复用上次成功结果。
- 离线 HTML 与真实联网获取分别标识，不能把前者冒充后者。
- 文件摘要、字节数、字符数、编号、首尾摘录和消息元数据一致性。
- 正文重排、伪造追加、子串绕过、路径穿越和符号链接。
- 多页重组保持 Unicode、CRLF、特殊字符和超长单条消息完整。
- 空页或越界 offset 不能被当成已读成功。
- 文件校验回执与实际正文读取回执分开。

还对参考项目的 fixture 做过解析核对；其中的音频按设计被拒绝，不将缺失的音频内容当成全文。

首轮命令行记录使用通用 `FETCH_FAILED`。交付版另外识别上述代理 403，输出 `NETWORK_POLICY_BLOCKED`，此分支已有模拟测试，不需要再次请求同一链接。

## 边界

- 测试通过证明这些已知输入和失败情况符合设计，不是对未来页面格式的保证。
- 安装不会扩大账号或运行环境的联网、文件、代码执行权限。
- SHA256 与首尾摘录不能证明模型已经读完，技能要求逐段实际读取。
- 本地文件一致性不是对网站来源的密码学签名；原文中的事实仍需单独核查。
- 只能读取本次分享快照中支持的可见文字分支，不代表原账号的完整历史。
- 技能路由、模型上下文容量、遵守指令和回答准确率仍取决于客户端与模型，无法保证零幻觉。
